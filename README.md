# Verse — AU Story Studio

A mobile-first fictional social-media story creator. Build and export realistic chat and social post mockups across iMessage, X, Instagram, WhatsApp, Threads, and TikTok.

## Features
- Automatic local saving with no account required
- Create, edit, and delete projects
- Six platform mockups and light/dark previews
- PNG export at 2× resolution
- JSON project backup/import for moving work between devices
- Responsive phone-first editor

## Development
```bash
npm install
npm run dev
```
